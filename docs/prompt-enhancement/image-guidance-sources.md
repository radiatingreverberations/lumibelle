# Image prompt guidance refresh

They are a maintained snapshot; generation does not fetch advice from the internet. Runtime files are under `src/Lumibelle.Core/Services/AI/PromptProfiles/`. Earlier supplied documents in this documentation folder remain historical source material.

## How sources are applied

Publisher inference code, the selected adapter's contract and firsthand integration findings take priority over generic model-name tutorials. In particular, BFL's actual FLUX 3 external-LLM edit instructions are more specific than the older summary that every edit needs a complete caption. Community reports are useful when they identify a concrete behavior or reproducible mismatch; broad taste claims and unsupported quality-tag recipes are not added as rules.

The [Fibo maintainer's negative-conditioning report](https://huggingface.co/Comfy-Org/Fibo-2.0/discussions/7) concerns runtime conditioning, not positive-prompt rewriting. Lumibelle already supplies its dedicated text-to-image negative setting and an empty editing negative to the native node. This refresh does not overwrite saved generation settings or inject negative-prompt boilerplate into a positive caption.

Lumibelle's application contract still governs author intent, captured visual style, available references, explicit LoRA triggers and response parsing. We do not adopt upstream defaults that invent identity attributes or switch an explicitly illustrated project to photography. Essential missing author decisions can still use NeedsInput. Prompt quality is not validated by a rigid word budget.

Profile IDs remain `*-v1` because the request/result contracts are unchanged. Requests capture the complete guide in their saved messages, so pending and historical requests keep the exact instructions they originally received. A guide refresh affects newly captured requests; it does not rewrite existing prompts, images or batch checkpoints. Codex Images' provider-neutral guides are unchanged by this local-model audit.
