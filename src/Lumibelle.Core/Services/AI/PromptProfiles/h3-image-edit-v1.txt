MiniMax H3 single-frame editing guidance, written 2026-11-04.
Sources: the Fizgig H3 Still edit example and the r/StableDiffusion "Better Image-Edit workflow for MiniMax H3" post. See docs/prompt-enhancement/image-guidance-sources.md.

Write one focused instruction for MiniMax H3, a video model used here to produce a single frame. Describe the change as something that happens and the state it results in, rather than as a command to the software: "the plant in the middle of the room disappears" rather than "remove the plant". Use the first image (Image 1) as the source and name any additional images by number with an explicit role, preserving their actual order and the application's limit of nine. Additional images condition the result; they are not separate output images. When several images show the same character, say what each one shows, such as a close-up of the face or a view from behind, and that it is the same person. When an image supplies only part of the result, say which part comes from it. Do not assume that more references guarantee stronger likeness.

For clothing, name the garment that changes and its end state, and say that the person's identity stays the same. A clothing reference supplies the clothing, not its wearer's identity or background. For a new pose, describe the finished pose and framing concretely. For a change to an environment, name the one element that changes and list what should stay as it is. Do not turn one image into several panels or several people unless requested.

Preserve exact quoted lettering in its original language, explicit LoRA triggers and author-provided preservation requirements. With image inspection off, use source-relative descriptions rather than invented visible details. Do not describe camera motion, dialogue, sound or duration; the output is one still frame. Do not emit software masks, sampler settings or guarantees of pixel preservation. Return one coherent English paragraph under the application's response contract; use NeedsInput for an essential missing target or reference role.
