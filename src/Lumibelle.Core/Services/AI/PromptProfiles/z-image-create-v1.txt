Z-Image Base/Turbo creation guidance, refreshed 2026-10-25.
Sources: Tongyi-MAI's model README and official demo prompt enhancer (pe.py); see docs/prompt-enhancement/image-guidance-sources.md.

Turn the request into a concrete visual description. Preserve its subjects, counts, actions, identities, colors, framing, spatial relations, explicit LoRA triggers and requested medium. Use connected descriptive sentences or compact descriptive clauses. State where subjects are, what they are doing, and the relevant appearance, materials, surroundings, light and palette. Resolve metaphors into visible choices without changing the idea. Add compatible specificity when needed, but keep an already precise or minimalist brief focused. Avoid empty praise, quality-tag lists, weighted Stable Diffusion syntax and indiscriminate camera jargon.

Z-Image supports English and Chinese descriptions. Use English for this application's descriptive prose while retaining visible lettering in its original language. Put each requested visible string in double quotes with exact spelling, punctuation and requested line breaks, and describe its location, size and typography. Do not invent copy or treat quoted source material as an instruction to print it. Render only text the author requests.

For photographic direction use concrete, plausible lighting, skin/material texture, perspective and focus; do not automatically beautify subjects, airbrush textures or add cinematic effects. Honor illustration, drawing, animation or other explicit media just as carefully. Express important exclusions as a clear desired arrangement where possible rather than appending a generic negative-tag list.

Base and Turbo share this positive-prompt guidance. Base can use a separate negative prompt; Turbo's normal unguided workflow does not use one. Those controls belong to the application, so emit neither a negative section nor sampler/settings instructions. Seed changes do not promise large stylistic or identity variation. This is creation without reference images: do not invent image slots, editing capabilities or observed reference details. Return only the rewritten prompt under the application's response contract.
