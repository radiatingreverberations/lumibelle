Qwen Image 2.1 — image-editing prompt guidance

Sources rechecked 2026-10-25 against Qwen-Image-2.1's model card and ComfyUI integration. See docs/prompt-enhancement/image-guidance-sources.md.

Write one clear English edit instruction. <image1> is the edited base image. Additional supplied slots, <image2> through <image10>, are references, not additional images to edit. Never fabricate, drop, reorder or renumber slots. Identify which requested attributes to transfer from each relevant reference and which attributes to preserve from <image1>. Use these exact slot tokens, not the older Picture syntax.

State the requested changes and the preservation constraints together. Preserve identity, face, hair, proportions, pose, composition, materials, lighting or background only where consistent with the author's intended change. Do not let clothing or backgrounds in secondary references replace unrelated base-image details. Distinguish identity references from clothing, object, environment and composition references. Prefer concise unambiguous instructions over repeated claims of quality.

Respect the supplied output aspect: From Image 1 follows the first image and its crop; an explicit aspect selects a separate output canvas. The application scales references using its chosen pixel budget. Do not insert an arbitrary aspect ratio or output implementation settings. There is no Krea identity-edit LoRA or reference-boost parameter. When regional Edit/Protect selections are supplied, preserve the exact prepared canvas, placement and scale. Opaque gray protected areas and padding are placeholders: leave them unchanged. Lumibelle restores protected original pixels and places the edited region back at its original coordinates during review. Protection on additional references only hides their selected pixels; those references are never pasted into the result. Without regional selections, do not invent software masks or protection guarantees. A separately supplied annotated image remains an ordinary numbered reference.

When image inspection is off, use source-relative language grounded in the supplied descriptions; never claim to have seen the images or invent unseen clothing, faces or text. Preserve the author's explicitly quoted lettering and LoRA triggers exactly. Request an RGBA transparent background only when the author asks for one; otherwise preserve the requested or base background.

Return only the rewritten prompt under the application's response contract. When a structured response is requested, place the complete prompt inside its text field. Use NeedsInput or NeedsSetup for essential missing inputs or an actual unsupported workflow requirement.
