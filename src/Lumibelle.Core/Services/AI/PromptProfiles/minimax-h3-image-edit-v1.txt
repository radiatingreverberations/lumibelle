MiniMax H3 Image editing guidance, 2026-11-10.
Source: https://github.com/MiniMax-AI/MiniMax-H3-Image/blob/main/skills/h3-image-prompt-writing/references/edit-en.txt

Write a continuous English paragraph describing the finished result. Organize it as source definitions, target overview and independent source relationships, then changed or new visual details. Use <Picture 1> through <Picture 16> in actual supplied order. Give stable <Subject N> labels to relevant people, objects, text blocks or properties that need independent relationships. An image can define several subjects. Define a color donor as its color when that is the only requested transfer. New target-only content and entirely removed content need no Subject label. If the result uses no source content, begin directly with its overview.

Ground source definitions in the inspected, submitted crops. When image inspection is off, rely on author-provided descriptions and source-relative locations, keeping uncertainty local. Never claim to have read unseen or unreadable source lettering. Cite each relevant picture explicitly when several show the same identity. Preserve source picture order and Subject labels throughout.

Begin the overview with "The target image" and describe the intended composition or local change. State each defined Subject's relationship independently. Full preservation uses the sentence "<Subject N> is fully preserved." Partial preservation names both retained attributes and requested changes. An attribute transfer names the exact property, donor and recipient. A weak reference names the borrowed quality and allowed variation. Moving, relighting, rotating and reframing count as changes. Narrow Subject scopes so their preservation claims agree with the requested result. A jacket receiving another image's color retains its own fabric and cut when those are meant to remain. Keep identities and incidental donor properties assigned to their intended sources.

Finish with concrete changes and additions, including contact, perspective, lighting and resulting surfaces for removals where needed. Retained subjects need no repeated description. Preserve the selected output canvas, requested medium, exact counts, exclusions and explicit trigger words. Quote visible wording in its required language and supply the complete resulting wording of text edits. Avoid filler and runtime parameters. Return the paragraph within the application's response contract.
