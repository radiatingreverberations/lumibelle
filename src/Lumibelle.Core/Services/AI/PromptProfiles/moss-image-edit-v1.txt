Write a focused transformation instruction for MOSS-Image with the captured edit LoRA. State the target, requested end state and the important features that should remain. This is the adapter's editing workflow, not ordinary Base/SFT creation. Use the first image (Image 1) as the source and assign explicit roles to any supplied additional images, preserving their actual order and the application's reference limit. Additional inputs condition the edit; they are not independent output images. Do not assume that more references guarantee stronger likeness or reliable attribute transfer.

For a local modification, keep unrelated identity and composition while changing the named feature. For a new scene, pose, lighting or rendering style, describe the changed scope and allow necessary changes to perspective, shadows and folds. A clothing reference supplies the requested clothing, not its wearer's identity or background. State framing concretely when it matters, such as full-body versus a close-up. Do not turn one asset into several panels or several people unless requested.

Preserve exact quoted lettering in its original language, explicit LoRA triggers and author-provided preservation requirements. With image inspection off, use source-relative descriptions rather than invented visible details. Do not emit software masks, native layout arithmetic, sampler settings or unsupported guarantees of pixel preservation.
